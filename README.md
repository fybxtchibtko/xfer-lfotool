## Overview

LFOTool is the industry standard for trance-gate and sidechain-pump effects, using a fully customizable LFO shape editor to create precise volume automation envelopes synced to DAW tempo.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Xfer LFOTool** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Shape Editor** | Draw any LFO waveform with up to 128 breakpoints and curve handles |
| **Tempo Sync** | Lock LFO rate to beat divisions from 1/32 to 16 bars |
| **Preset Library** | 200+ factory shapes for pump, gate, tremolo, and tremolo variation |
| **MIDI Trigger** | Retrigger LFO on MIDI notes for rhythmic gate effects |
